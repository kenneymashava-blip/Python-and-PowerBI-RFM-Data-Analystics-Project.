# Python-and-PowerBI-RFM-Data-Analystics-Project.

This project focuses on data cleaning, and Frequency,Recency and Monetary analysis of the Kaggle's E-commerce dataset using python,
and building of RFM Dashboard in PowerBI. This project is devided into three sections: 

- **Data cleaning and quality checks in python.**
- **RFM Analysis in python.**
- **Dashboard development in Microsoft PowerBI.**
